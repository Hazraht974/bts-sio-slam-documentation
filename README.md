# BTS SIO SLAM — Documentation technique

Cet espace regroupe les documents et les ressources nécessaires à la présentation du projet dans le cadre des épreuves du BTS SIO SLAM.

## Contenu de la documentation

- Contexte du projet : consignes et contexte fournis par le professeur.
- Scripts de base de données : scripts SQL utilisés pour créer et gérer la base de données.
- Fiche descriptive RP1 : présentation et description du projet.
- Rapport de projet : document détaillant le travail réalisé.
- Schéma de données : Modèle Conceptuel de Données (MCD) et Modèle Logique de Données (MLD).
- Code source : versions compressées des projets au format ZIP.

## Objectif

Centraliser les documents techniques et les livrables du projet afin de faciliter leur consultation par les jury.
